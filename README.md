# Parrhesia (παρρησία)

**Модульный аудио-микшер для Windows.**

**Parrhesia** — виртуальный аудио-микшер для Windows: принимает звук от любых
приложений и устройств, смешивает его и отправляет куда нужно. Название — от
греческого *παρρησία* («свобода говорить всё, открыто и смело»): у Parrhesia
звук идёт туда, куда вы его отправите, без лишних рамок.

## Особенности

- **Модульная маршрутизация** — входы, выходы и шины собираются под задачу: от
  стрима с десятком источников до простого «микрофон → динамики». Ни одного
  жёсткого лимита — схема растёт вместе с вами.
- **Любая схема** — каждый источник можно отправить сразу в несколько
  назначений, а схему пересобрать в любой момент без перезапуска.
- **Удобный интерфейс** — понятная современная панель, где нужное всегда под
  рукой.
