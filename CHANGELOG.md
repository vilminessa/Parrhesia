# Changelog

Все заметные изменения Parrhesia. Формат-модель: версия живёт в git-теге
(`v*`/`b*`); dev-сборки показывают «unreleased».

## Unreleased

### Волна S — плагины как узлы схемы (изоляция процессов)
- Каждый VST3/CLAP = узел-плагин, исполняемый в **отдельном процессе**
  через аудио-мост: крэш/зависание плагина не касается приложения.
- Состояние/параметры через управляющий канал; редактор плагина открывается
  окном в его процессе; авто-restart умершего исполнителя и ретраи
  спавна с бэкоффом (завис → раз в минуты; падение → секунды).
- UI: «Плагин…» в палитре схемы, авто-wire в разрыв кабеля, инспектор со
  статусом процесса (жив/pid/пропуски/обратный отсчёт ретрая), кнопки
  «Перезапустить» и «Редактор…».
- Слоты-вставки живут только на узлах-плагинах; легаси-профили «шина +
  слот» мигрируются автоматически; песочница VST3 удалена.

### Волна T — диагностика и честные счётчики
- Умный бэкофф ретраев плагинов с классификацией «завис / упал»;
  инспектор показывает обратный отсчёт до следующей попытки.
- Статус движка показывает фактический квант тракта (устройственный
  минимум WASAPI shared).
- Спящие кольца источников (звук никуда не идёт) больше не копят ложные
  xrun: статус «0/0» вместо миллионов, отчёт задержки не портится
  ложным [bad]; по-источниковая строка в логе показывает, кто копит и
  кто спит.
- Захват отдельного приложения: публичного API в Windows нет — в палитре
  честная подсказка про виртуальный кабель.

### Релизная инфраструктура
- `scripts/publish.ps1` — Release-публикация (папка + zip), проверка
  нативного шима; `-SelfContained` для сборки без рантайма.
- CI (GitHub Actions, windows-latest): сборка + полный гейт на каждый
  push/PR; best-effort сборка нативных VST3-артефактов; на тегах `v*`/`b*`
  — публикация версии из тега артефактом.

### Ранее (сводка волн G/H/K/D/P)
- Зоны и группы микшера, wrap-сетка, ресайз пультов, FX-чипы стадий.
- Темы сидов v2 с миграцией; контраст/акценты.
- P-волна: фоновая загрузка слотов, пауза цепочек перед state/prepare,
  ComGuard.
